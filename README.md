# Homework 1 – MCP Server

## Voraussetzungen

- Python 3.11 oder neuer
- [uv](https://docs.astral.sh/uv/)

## Installation

```bash
uv sync
```

## Tests ausführen

```bash
uv run pytest
```

## MCP-Server starten

```bash
uv run python mcp_server.py
```

Die LiteLLM-Konfiguration wird später über eine lokale `.env`-Datei eingerichtet.
